# Casa Arthur 3D

Visita livre à casa no navegador: o `index.html` da raiz é um redirector —
telemóvel/tablet vai para `leve/` (versão leve: GLB com texturas ≤512 px,
render a 0,5×) e computador vai para `pc/` (versão completa).
Escolha manual: `?v=leve` ou `?v=pc` no endereço.
Câmara livre, corte por altura, medidas dos cômodos, medir distância e medir área.
